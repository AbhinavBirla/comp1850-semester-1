# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists everything that is in the current directory |
|     cd directory_name       | changes the current folder into the provided directory name|
|     cd ..                   | moves up one directory level |
|     cd -                    | goes back to the previous folder you were in|
|     mkdir directory_name    | creates a new folder with the provided directory name|
|     touch filename          | creates a new empty file named filename |
|     git status              | shows which files have changed and the current state of your git repository |
|     git add -A              | it helps to stage your changes and tells git you want to save |
|     git commit -m ""        | bundles these changes to one commit, this is basically a way to create a save point |
|     git push                | send all the changes back to remote github server where it is stored |
|     git pull                | downloads latest changes from the remote repository and merges them into your local copy |
